# Security Policy

## Reporting a Vulnerability

We take the security of MkopoSwift-GRC seriously. If you discover a security vulnerability or a flaw in the compliance logic, we encourage you to report it to us as soon as possible.

Please **DO NOT** open a public issue on GitHub for security vulnerabilities. Instead, please report it privately via email to:

**dpo@mkoposwift.co.ke**

When reporting, please include:

*   A clear description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   The potential impact of the vulnerability.
*   Any suggested mitigations (if applicable).

We will acknowledge your report within 48 hours and aim to provide a more detailed response within 5 business days. We appreciate your efforts to responsibly disclose security issues.

## Supported Versions

The following versions of MkopoSwift-GRC are currently supported with security updates:

*   `main` branch (latest development)

We encourage all users to use the latest version of the software to ensure they have the most up-to-date security patches.
