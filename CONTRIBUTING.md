# Contributing to MkopoSwift-GRC

Thank you for your interest in contributing! 

This repository serves as a demonstration of offline-first compliance engineering, specifically tailored for the Kenyan fintech market and the Kenyan Data Protection Act (2019).

## How to Contribute

We welcome improvements, bug fixes, and expansions to the dataset or compliance scenarios. 

1. **Fork the repository** to your own GitHub account.
2. **Create a new branch** for your feature or bug fix.
3. **Make your changes**, ensuring that any new code maintains the offline-first philosophy and passes the cryptographic vault integrity checks.
4. **Update the vault hashes** if you modify core files (otherwise the CI pipeline will fail).
5. **Submit a Pull Request** with a clear description of your changes and how they improve the compliance appliance.

For major changes or architectural discussions, please open an issue first to discuss what you would like to change.

## Security

If you discover a security vulnerability or a flaw in the compliance logic, please report it privately to dpo@mkoposwift.co.ke rather than opening a public issue.
