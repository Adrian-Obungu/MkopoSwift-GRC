# Contributing to MkopoSwift-GRC

We welcome contributions from compliance engineers, fintech developers, and anyone passionate about data protection and GRC. By contributing, you help us build a more robust and secure platform for Kenyan digital credit providers.

## How to Contribute

1.  **Fork the Repository:** Start by forking the `MkopoSwift-GRC` repository to your GitHub account.
2.  **Clone Your Fork:** Clone your forked repository to your local machine:

    ```bash
    git clone https://github.com/YOUR_USERNAME/MkopoSwift-GRC.git
    cd MkopoSwift-GRC
    ```

3.  **Create a New Branch:** Create a new branch for your feature or bug fix. Use a descriptive name (e.g., `feature/add-new-module` or `bugfix/fix-breach-script`).

    ```bash
    git checkout -b feature/your-feature-name
    ```

4.  **Make Your Changes:** Implement your changes, ensuring they adhere to the project's coding standards and do not alter existing source code files (`.py`, `.sql`, `.db`, `.log`, `.sh`, `.yml`, `.json`, `.dockerfile`). Focus on documentation, community files, or new, non-source code features.

5.  **Test Your Changes:** If applicable, ensure your changes are thoroughly tested.

6.  **Commit Your Changes:** Write clear and concise commit messages.

    ```bash
    git add .
    git commit -m "feat: Add descriptive commit message"
    ```

7.  **Push to Your Fork:** Push your changes to your forked repository.

    ```bash
    git push origin feature/your-feature-name
    ```

8.  **Open a Pull Request:** Go to the original `MkopoSwift-GRC` repository on GitHub and open a new Pull Request from your branch. Provide a detailed description of your changes and why they are valuable.
